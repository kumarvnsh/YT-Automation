ACTIVITY FEED

From the team

Set up your team · six simple steps＋
01 / PICK THE CHANNEL

Choose your office

Use the channel selector above. Tasks, notes and routines belong to the selected channel. Jarvis and Operations have separate routines in each.

02 / CHOOSE A DESK

Give one clear job

Select a bot, then use “Use suggested routine” below. Edit its assignment to match the question you want answered.

03 / ADD CONTEXT

Save standing notes

Add your preferences and constraints, then press Save notes. Notes and the last two completed reports are included in future reviews.

04 / ENABLE THE ROUTINE

Set the cadence

Choose Superbot or Dashboard analyst, select an interval and press Save routine. The first scheduled run starts after that interval; unfinished work does not stack.

05 / TRY A FIRST RUN

Assign task now

This queues a review immediately without changing your routine. Watch the desk switch from queued to working, then open the finished report below.

06 / CLOSE THE LOOP

Review, test, remember

Choose a recommendation to implement. Save what you changed and its outcome in standing notes so the next review can learn from it.

What runs on its own: enabled routines, evidence review and report creation while this laptop and the dashboard service are running. You can close this page.
